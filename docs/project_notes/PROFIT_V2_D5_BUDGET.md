## 1. 预登记规则（在运行之前固定）

| # | 规则 |
|---|---|
| 1 | **每期组数固定，不允许动态减少组数**。自适应仓位是一种新策略，超出本轮范围；允许它会把"预算约束"变成"择时仓位"。 |
| 2 | **参与日期规则固定**：政策在窗口（22145–26042）内**每期都尝试参与**，不择时。 |
| 3 | **先检查、后参与**：每期开始前判断 `已实现亏损 + 未结算暴露 + 本期成本 ≤ 限额`。不满足则该政策**永久停止**（记录 `stopped_at_issue`），之后的期次一律记 0 组、0 收支。跳过本期等下一期再试属于隐性择时，本轮不允许。 |
| 4 | **当期立即结算**（同一期同一账户合并计税，见 D2 账本）。 |
| 5 | 三个指标**分开报告**：`budget_stop`（因额度不足停止）、`touched_limit`（累计亏损**达到**限额）、`over_limit`（**严格超过**限额）。 |

> 规则 3 的直接后果：**先检查后参与**保证参与后的累计亏损**不可能超过**限额，
> 因此 `over_limit` 在设计上恒为 0；若非 0 即说明预算检查有缺陷。
> 本轮的实测值全部为 **0**。

### 3.1 三个指标为什么互不相同（要点）

- **因额度不足停止**：全部政策都发生了，且发生得**很早**（第 1–7 期）；
- **实际触及亏损上限**：**全部为"否"**。因为停止发生在"剩余额度 < 本期成本"时，
  此时累计亏损**尚未**达到限额（例：P1_a 在 3 期后亏 396，剩 104 < 132 即停止，
  从未到 500）；
- **超限违规**：**全部为 0**，符合规则 3 的设计。

> 换句话说：**在 500 元预算下，账户根本来不及亏到限额就被迫退出了。**
> 这与"把钱亏完"是两件不同的事，必须分开报告——本轮的三个指标没有任何混用。

## 4. 起点敏感度（回应"不能事后挑日期"）

窗口内的起点本身是一个选择。为避免"事后挑一个好起点"，对**窗口内全部 450 个
起点**各跑一遍完整模拟：

> ⚠️ **这 450 个起点高度重叠（同一个 500 期窗口内的平移），
> 不是 450 次独立验证**，不得当作独立样本或用于显著性推断；
> 它只用于回答"结论是否依赖于起点选择"这一个稳健性问题。

| 限额 | 政策 | 参与期数（均值 / 区间） | 净利（均值 / 区间） | **正收益起点占比** |
|---|---|---|---|---|
| 500 | `P1_a` | 4.06 / [3, 18] | −394 / [−491, −372] | **0.000** |
| 500 | `P2` | 1.40 / [1, 12] | −273 / [−474, −248] | **0.000** |
| 500 | `P3` | 1.11 / [1, 5] | −346 / [−483, −129] | **0.000** |
| 1000 | `P1_a` | 9.37 / [7, 25] | −914 / [−993, −870] | **0.000** |
| 1000 | `P2` | 4.12 / [3, 15] | −809 / [−990, −743] | **0.000** |
| 1000 | `P3` | 2.46 / [2, 6] | −766 / [−974, −626] | **0.000** |

**结论对起点稳健**：450 个起点中，**没有一个**能在这段窗口内产生正的净收益。

## 6. 对"500/1000 元约束是否适合继续验证"的回答

| 问题 | 回答 |
|---|---|
| 500 元能支持多少期验证？ | **1–3 期**（起点敏感度下均值 4.06 期，区间 3–18） |
| 1000 元呢？ | **2–7 期**（均值 9.37 期，区间 7–25） |
| 这个样本量能做统计推断吗？ | **不能**。D4 §6 已给出：该分布在**可靠功效意义上未确定** —— 期望收益由概率 3.08×10⁻⁶ 的一等奖主导，本轮窗口内一次都没出现。 |
| 三个指标是否警告了风险？ | 是：政策在第 1–7 期就被额度不足强制退出，"触及上限"一次都没发生——**约束先于上限起作用**。 |
| 结论 | **500/1000 元不适合用于获得统计证据。** 它只能支持"纸面验证"或"直接结束研究"，不能支持真实投注试验。 |

**这与 PLAN §5 的判断一致**："在零回收压力情景下 500 元仅容纳 3 个 132 元单元……
这一规模不能通过实际投注获得充分统计证据。"
