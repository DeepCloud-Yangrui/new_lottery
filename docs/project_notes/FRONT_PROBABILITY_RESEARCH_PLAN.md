## 1. 问题与成功定义

预测下一期35个前区号码各自入选的概率，固定取Top-5形成一组5+12。先检验概率是否比均匀基线准确，再看选号命中及完整收益。最终目标仍为含一二等奖的税后净盈利，但本阶段只可能提供预测增益的证据，不能跳过盈利验证。

不把排序后的五个位置当独立目标，不把35个号码记录当35倍独立样本，不把边际概率相乘当作五号码联合概率。Top-5优化的是边际概率模型下的预期命中数，不保证中3+概率或收益最优。

## 2. 范围与资源

- 仅模拟、单组5+12、每期132元，不追加、不倍投。不上线、不实际投注、不启用前瞻/调度。
- 统一使用服务器独立研究环境；U/F/L/R使用CPU，固定小型MLP使用一张空闲GPU。保留旧TensorFlow环境，不做多卡训练或参数搜索。

- 建议3个工作日上限：协议/测试、训练评估、结论各1日。不自动延期，不购买资源。执行前记录实际耗时预算；超时保存已完成结果，不以少跑的结果冒充完整比较。
- V3使用的奖金模块只读复用已验证版本；若V3仍在写同一模块，本阶段先完成概率与命中评价，收益部分等待版本固定，避免共享文件冲突。

## 3. 预登记五个候选（不搜索参数）

| ID | 模型 | 固定规则 |
|---|---|---|
| U | 均匀基线 | 每号5/35 |
| F | 平滑频次基线 | 最近100期，各号p=(出现次数+100×5/35)/200；总和恒为5 |
| L | L2逻辑回归 | 现有特征、35个二分类输出；C=1、lbfgs、max_iter=1000、无class_weight |
| R | 现有RF结构重训 | 300树、max_depth=8、min_samples_split=8、min_samples_leaf=3、seed=42；每折独立训练 |
| N | 小型MLP | 隐藏层64/32、ReLU/Dropout0.1；17/42/2026固定三种子平均；内部时间验证早停与全训练折重训，精确配置以SERVER_F1_HANDOFF_PLAN.md为准 |

不使用`model/dlt/rf_front_model.pkl`作为所有历史期的预测模型，因为其训练截止22096，不保证适用于任意历史评估区间。新模型只能读本折目标期之前的标签。

L标准化只在训练折fit；F不调窗口；R不改权重/深度/候选池。N仅做预登记的三种子平均，不融合不同模型。若L不收敛，记录失败并诊断数值，不通过试多个超参数选择最好结果。

## 4. 数据与特征

复用`feature_engineering.build_front_training_dataset`与`build_front_feature_row`，窗口10/30/100、min_history=120，标签为35维0/1且每期恰好5个1。按期号升序，检查重复期、缺失、号码范围和前区重复号码。

每个目标期特征只依赖此前开奖。不输入当期号码、当期实际奖金额、目标期后的统计量。训练和预测分离，禁止对全量数据fit标准化或校准。

选定一个本地完整快照，记录截止期、hash、来源和哪些期次已暴露。≤26116期已用于研究；更晚数据是否被其他研究用过不能猜测。所有使用过的数据本轮只称“时间顺序历史评估”，不称新的未见测试。

## 5. 时间顺序评估

默认最近800个可建模目标期分成4个连续且互不重叠的200期评估块；每块使用其之前全部可建模期训练，首块训练期不得少于500。数据不足时停止并报告，不事后缩窗口以寻找优势。

每块开始时冻结模型与标准化参数；块内可使用已经开奖的前期数据生成下一期特征，但不更新模型权重。每期先保存概率再对照标签。所有候选使用完全相同的期次。

四块评估期不重叠，但训练集重叠，不能宣称四次独立实验。已暴露数据上的改善只能产生后续候选，不能证明未来可复现。

## 6. 概率输出与选号

- 保存原始概率`p_raw`以及固定处理后的`p`，所有35个号码均有记录。
- L/R/N使用固定logit偏移：先将概率限制到[1e-8,1-1e-8]，求共同常数a使sum(sigmoid(logit(p_raw)+a))=5。N先对三种子原始概率平均。用确定性求根，绝不使用目标标签。
- U/F本身总和为5，不作额外变换。主指标统一评价最终p；原始概率只用于诊断，不能事后择优挑口径。
- 这是固定数量一致性修正，不称为经过验证的概率校准；真实校准靠评价检查，首轮不新增校准器。
- 固定Top-5，不做过滤、缩水或融合。完全相等的概率使用事先确定的、按期号与固定种子20261013生成的打破平局顺序；不根据中奖结果选顺序。
- RF单类别输出须根据classes_定位标签1；仅类0时正类概率应为0，禁止把单列概率1当作正类概率。
- 每期记录issue/model_id/fold/train_end/model_hash/p_raw/p/top5/feature_snapshot_hash，训练截止严格早于预测期。

## 7. 指标与结论边界

### 主指标：按期平均Brier loss

每期Brier=(1/35)sum((p_j-y_j)^2)，35号先合成一个期级损失。主要对比L-U、R-U、N-U，正增益定义为baseline_loss-model_loss。F作为简单历史基线；同时报告模型是否只是改善了另一种较差方法却没有超过U。

次指标：按期平均binary log loss（明确是边际评分，不是整组联合似然）、固定分箱校准图、预测概率范围和sum(p)。不要用“是否入选”的分类准确率，恒猜不入选就会获得很高准确率。

选号指标：Top-5平均命中、K=0..5分布、K≥3/4/5；均匀基线下平均命中应为25/35，K≥3用精确超几何作参考。中奖稀有事件不得由边际分数改善直接推断。

收益指标：同一组Top-5、同一批期次，调用已验证计奖/税务入口。报告完整税后净收益、费用缺口、大奖贡献、回撤；零大奖样本的方差不用于完整收益功效推断。收益只作本阶段次要诊断，不以其最优选择模型。

### 不确定性与晋级规则

- 分析单位是期，比较同一期损失差，不把号码、模拟种子或重叠训练折算独立样本。
- 预先选连续块重抽样，block_length=20，50作敏感性，2000次，seed=20261013；说明平稳性/相关结构假设，区间仅作历史诊断。
- L/R/N三个主对比报告同时区间（Bonferroni家族alpha=0.05，每个双侧98.333333%区间，尾概率0.05/6），禁止无调整地挑最好模型。
- 探索晋级需要：总体Brier较U改善、至少3/4时间块方向一致、两种块长度下经调整的区间下界均>0、总体logloss不高于U且Brier不高于F；校准用固定10个等宽箱描述，不作主观放宽。
- 即使通过，上述也只能称“值得冻结后验证的候选”，因为数据已暴露。未通过就关闭本轮，不启动新模型搜索。
- 如多个候选通过，按预登记总体Brier最低者选一个，差≤1e-12视为平局，优先L、R、N。Top-5/利润不能覆盖主指标选择。
- 通过预测晋级不等于盈利达标；后续真实未见数据验证、联合命中和收益决策要另立协议，本阶段不自动推进。
