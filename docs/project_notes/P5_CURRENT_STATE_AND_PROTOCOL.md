### 3.2 最大回撤口径 —— 已确认并修复

`compute_strategy_metrics` 等函数用 `cum = cumsum(profit)` 后取 `max(peak - cum)`，
由于 `peak[0] == cum[0]`，**第一期就亏损的情形不计入回撤**。
已改为以 0 为资金曲线起点。自检：`[-132, 50, -132, -132]` 旧口径 264 元，新口径 346 元。

### 3.3 截断 ROI 的单位不一致 —— 已确认，保留但降级为辅助指标

`roi_truncated` 对**每期** `reward` 施加 `cap=10000`，而"每期"在不同策略里含义不同
（单组 132 元 / 三组 396 元 / 门槛策略的下注期与跳过期）。跨成本结构比较不可靠。
新增 `roi_no_jackpot`（把 (5+2)、(5+1) 的奖金置零后重算 ROI），口径与成本结构无关，
作为主稳健指标；`roi_truncated` 仅用于同成本结构下的辅助对照。

## 4. 5+12 机制的精确定义与结构性事实

（详见 `P5_PROFITABILITY_VERDICT.md`，此处只列协议所需）

- 一组 5+12 = 固定前区 5 码 + 后区 1~12 全包 = C(12,2) = **66 注**，
  基本投注 2 元/注，不追加、不倍投 → **132 元/组**。
- **后区命中分布是恒等式**：对任意前区组合、任意开奖后区，
  66 注中「中 2 个」1 注、「恰好中 1 个」20 注、「中 0 个」45 注。
- 因此单组回收只是"前区命中数"的函数 `R(f) = Σ_b n_b × prize(f,b)`。
  前区中 0/1/2 个**也有回收**（5 元 / 5 元 / 115 元），不得当作零。
- **后区全包不改变期望值**：`E[一组回收] = 66 × E[单注奖金]`，
  全包只是消除后区不确定性，不提高期望。
- 多组方案的成本与奖金**线性累加**（132 × 组数），但组与组之间高度相关
  （共享候选池、前区号码重叠），因此多组不会按 √n 降低风险。

   **在协议冻结之后**才允许用于评估。
3. 74 期 × 132 元 = 9,768 元（单组）/ 29,304 元（三组）的样本量，
   对"是否盈利"这一问题**统计功效极低**：单期收益标准差在万元量级，

## 7. 评估指标（口径冻结）

| 指标 | 定义 | 用途 |
|---|---|---|
| `roi` | `(Σreward − Σcost) / Σcost`，**原始值，必须报告** | 主口径 |
| `roi_no_jackpot` | 把 (5+2)、(5+1) 的奖金置零后重算 ROI | 主稳健指标 |
| `roi_truncated` | 每期 reward 截断到 10000 元 | **辅助**，仅同成本结构比较 |
| `expected_roi` | 数学零假设下的期望 ROI（解析） | 判断是否超过随机基线 |
| `max_drawdown` | 资金曲线**从 0 起算**的最大回撤 | 风险 |
| `max_consecutive_loss` | 最长连续亏损期数（calendar / bet 两种口径） | 风险 |
| `hit3_or_more_rate` | 至少一组前区命中 ≥3 的期数占比 | 触发率 |
| `z / 标准误` | 相对随机对照分布的标准化差异 | 显著性 |

**明确区分三个概念**（报告中不得混用）：

- **命中概率**：某期至少一组中 3 个前区的概率；
- **期望收益**：长期平均回收 − 成本，由奖金表与命中分布决定；
- **短期盈利概率**：N 期内累计为正的概率，由方差与偶发大奖决定。

**禁止**：用"随机基线均值"当作盈利门槛。策略跑赢随机不等于 ROI > 0。

## 8. 继续 / 停止判定标准（事前写定）

按顺序回答四个问题：

**A. 当前实现与回测是否可信？**

- A1 计奖：`prize_rules` 的表与官方逐期数据一致（单元测试覆盖）；
- A2 无前视：特征、RF 训练截止、信号门槛阈值均只使用目标期之前的数据（单元测试覆盖）；
- A3 计账：成本/奖金/重复票/回撤口径有测试覆盖；
- 任一不满足则 A = 不可信，先修复再谈结论。

**B. 策略是否有可复现的随机基线优势？**

- 在样本外窗口（26043–26116）与回顾窗口（最近 200/500/1000 期）上，
  对 `roi_no_jackpot` 与 `hit3_or_more_rate`：
  - **有优势**：样本外 `roi_no_jackpot` 超过 C1 与 C2 分布均值，且
    z > 1.96（近似 5% 单侧），且在两个不同窗口上方向一致；
  - **微弱且无统计支持**：方向一致但 z < 1.96；
  - **无优势**：低于或与 C1/C2 无法区分，或方向在两个窗口上相反。

**C. 优势是否足以达到正期望（而不只是少亏）？**

- 正期望要求 `E[回收] >= 132`。随机基线 `E[回收] = 66 × E[单注奖金]`（约 71–83 元）。
- 因此正期望要求策略把 `E[回收]` 提高约 **1.6–1.9 倍**，
  等价于把 `P(前区 >= 3)` 提高约 **1.8–2.2 倍**（精确值见数学基线报告）。
- 只有在 B 判定为"有优势"**且**区间下界已把上述倍率基本补足时，
  才可判定"足以达到正期望"。否则一律判"少亏但仍为负期望"。

**D. 是否值得继续投入开发资源？**

- 若 B = 无优势 → **停止盈利导向研发**，保留研究工具；
- 若 B = 微弱但无统计支持 → **停止盈利导向研发**，仅保留"前瞻记录"这一零成本动作；
- 若 B = 有优势但 C 不满足 → 仅提出**证据允许的最小下一步**（例如先积累前瞻样本），
  **不自动进入 P3/P4**；
- 不得为了支持原路线而选择性报告。
