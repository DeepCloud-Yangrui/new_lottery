## A. 统计推断类

### A1. 「九候选池结构本身显著劣于全号池随机（z ≈ −9 ~ −11）」

| 项 | 内容 |
|---|---|
| **原说法** | 「C2（同候选池随机）vs C1（全号池随机）的 ROI 差 −10.4/−11.3/−12.6 个百分点，**z = −9.13/−9.93/−11.21**（p ≪ 0.001）」，并据此写「P3 只会放大同一个结构性问题」。 |
| **问题** | 该 z 的分母是**蒙特卡洛均值标准误** `sd/√n_trials`。它衡量的是"在**固定的这 74 期开奖**与**固定的这些候选池**下，模拟均值算得有多准"，会随 `n_trials` 增大而无限放大，**不是**对"候选池改变未来期望"的检验统计量。（同一个事实在 n_trials=100 与 100000 下会得到相差 31.6 倍的 z。） |
| **修正后说法** | 该差异在**正确的抽样标准误**下不显著：以"期"为单位，OOS 窗口的条件缺口为 **−15.09 元 ± 20.68 元（z = −0.73，剔除大奖口径）** / **−49.01 元 ± 214.86 元（z = −0.23，完整口径）**。已实现的候选池-开奖重叠 **m̄ = 1.22**，与零假设下的 **1.286** 一致。**九候选池结构与全号池的无条件期望相同**（见 B1 的精确证明）；本窗口的负缺口属于抽样噪声。 |
| **证据** | `tools/analysis_pool_conditional.py`；`corrections/pool_conditional_v2_withpools.json`；`corrections/SUMMARY.json` 的 `structure_test.status = RETRACTED_AND_REPLACED`；测试 `test_conditional_gap_standard_error_is_period_level`、`test_mc_se_is_not_a_hypothesis_test`。 |

### A2. 「P3（N+12 矩阵）必然放大同一结构性问题」

| 项 | 内容 |
|---|---|
| **原说法** | 「继续在这条路上迭代（P3 的 N+12 矩阵）只会放大同一个结构性问题。」 |
| **问题** | 这是从 A1 的错误 z 推出的因果预测，没有任何直接证据。 |
| **修正后说法** | **撤回**。可成立的只有：候选池会降低**组合覆盖的上限**并改变**方差/回撤**（见 B1 的精确矩计算），**不改变期望**。因此继续做 P3 的**收益理由不成立**（它不能凭空提高期望），但"必然更差"同样是未证实的。是否做 P3 是资源取舍，不是已被数学排除。 |
| **证据** | `corrections/math_baseline_scenarios_v2.json` 的 `structure_check.multi_group_exact_moments`。 |

### A3. 「74 期足以排除大优势」

| 项 | 内容 |
|---|---|
| **原说法** | 「74 期样本量虽小，但**足以排除"大优势"**」。 |
| **问题** | 没有给出"排除"的效应大小，且实际能排除的上限**高于盈亏平衡所需的命中率**。 |
| **修正后说法** | 精确结论：74 期观测到 1 次"前区 ≥3"，**单侧 95% 精确上限为 6.25%**（Clopper-Pearson 双侧 [0.03%, 7.30%]）。盈亏平衡所需命中率为 **2.60%–3.07%**。由于 **6.25% > 3.07%**，**74 期无法排除"达到盈亏平衡所需的前区命中率"**。它能排除的只是"命中率 ≥ 6.25%"这种量级以上的优势。 |
| **证据** | `tests/test_profit_math_v2.py::test_binomial_upper_confidence_bound_plan_checkpoint_625`（验算点 6.25%）、`test_three_percent_true_rate_is_not_rejected_by_74_periods`。 |

### A4. 「实测优势为零」

| 项 | 内容 |
|---|---|
| **原说法** | 「实测优势 ≈ 0 倍」。 |
| **问题** | 把"未拒绝零假设"说成了"效应为零"。74 期的置信区间很宽，本就无法证明"零"。 |
| **修正后说法** | **降级为「未发现优势」**。点估计为 1/74 = 1.35%，零假设 1.3865%，单侧 p ≈ 0.644 —— 观测与随机**完全相容**，但**不等于**"优势恰为零"。正确的说法是"本样本没有提供优势的证据"。 |
| **证据** | `test_observed_1_in_74_is_consistent_with_null`。 |

### A5. 「弱信号已被证明是选择效应」

| 项 | 内容 |
|---|---|
| **原说法** | 「回顾窗口的'名义优势'经样本外检验消失（选择效应），而非真实可预测性。」 |
| **问题** | (a) 表述为"已证明"过强；(b) 上一轮把三个嵌套窗口（1000 ⊃ 500 ⊃ 200，且都以 26042 结束）当成独立样本合并成 34/1700，得到 p = 0.0245 —— 这是**重复计数**的产物。 |
| **修正后说法** | 只取最大窗口：**18/1000 = 1.8%，单侧 p = 0.162，95% CI [1.07%, 2.83%]**，**包含**零假设的 1.3865%。全部四个窗口（200/500/1000/74）的 95% CI **都包含** 1.3865%，**无一能拒绝"随机"**。因此正确表述是：**「回顾窗口上的名义命中率优势未能获得统计支持，也未能用同一套信号在未被选参的窗口上复现；这与选择效应一致，但本数据不能证明它」**。 |
| **证据** | 本文件 §C4 的计算；`corrections/SUMMARY.json`；测试 `test_conditional_gap_standard_error_is_period_level`（同源口径）。 |

### A6. 「贪心覆盖 z = +4.0，因此缩水带来明确优势」

| 项 | 内容 |
|---|---|
| **原说法** | 「S2_441 的命中率 z = +4.00，百分位 0.730」，被当作缩水结构有效的正面证据。 |
| **问题** | 与 A1 同一个错误：z 用 MC 均值标准误。 |

| **证据** | `corrections/SUMMARY.json` 的 `structure_test.descriptive_mc_means_only`。 |

## B. 数学 / 公式类

### B1. 「候选池缩小 ⇒ 期望 ROI 更低」的隐含前提

| 项 | 内容 |
|---|---|
| **原说法** | 报告 §3.3.4 用「P(9 个号码含 ≥3 个开奖号码) = 9.46%」来说明候选池"给命中率设了天花板"，并把它当作同成本三组期望下降的证明。 |
| **问题** | 9.46% 是**该池自身**的一个零假设概率，**不能**推出同成本多组期望下降。 |
| **修正后说法** | **精确结论**：对**任意**固定 5 码组合 C 与均匀开奖 D，`|C ∩ D| ~ Hypergeometric(35,5,5)`，**与 C 是什么无关**（已对 324,632 个开奖 D 精确枚举验证）。因此：<br>• 单组的**无条件**期望回收与候选池大小/构成无关；<br>• 多组总回收的期望**按线性累加**（不要求组间独立）。<br>候选池改变的是**联合分布**：精确矩计算显示 3 组 200 期总收益的标准差为 **44,038 元（全号池）vs 44,406 元（9 号池，+0.8%）**；剔除大奖口径下为 **961 元 vs 1,021 元（+6.2%）**。即：方差略增、期望不变。 |
| **证据** | `corrections/math_baseline_scenarios_v2.json` 的 `structure_check.single_group_marginal_invariance`（枚举校验）与 `multi_group_exact_moments`（精确矩，无蒙特卡洛）；测试 `test_marginal_hit_distribution_independent_of_chosen_numbers`、`test_total_expectation_linear_in_groups`。 |

### B2. 盈亏平衡公式的三处缺陷（`tools/five_plus12_math.py::_breakeven_block`）

| 缺陷 | 说明 | 修正 |
|---|---|---|
| (a) 剔除大奖口径错误 | 旧实现把 `front_hit<=4` 之外的全部置零，**连 (5,0) 的固定奖也一起清零** | 新增 `no_jackpot_table()`：**只**置零 (5,2)、(5,1)，保留 (5,0)（依据官方规则第二十六条，每注只兑付其命中的最高奖级） |
| (b) 多组单位混用 | `need = cost_group×n_groups − L`，把整期成本与单组期望相减 | 盈亏平衡一律按**单组**口径 `cost_group` 求解；组数只按比例放大成本与回收 |
| (c) 缺退化保护与情景 | 未检查 q∈[0,1]，也未区分"如何提高命中率" | 新增 `breakeven_scenarios()`，给出 S1 整块搬运 / S2 只增 3 中 / S3 只增 4 中 三种情景，并对每个解给出**可达 / 已满足 / 不可达**判定；解为负或 >1 时显式标记而不是照抄数字 |

**证据**：测试 `test_breakeven_below_zero_when_low_hits_already_cover_cost`、
`test_breakeven_unreachable_flagged_and_bounded`、`test_breakeven_unit_consistency_across_group_counts`、
`test_no_jackpot_keeps_front5_fixed_prize`。

### B3. 「132/47.99 ≈ 2.75 倍 = 中 3+ 概率需提高约两倍」

| 项 | 内容 |
|---|---|
| **原说法** | 把"回收倍数"直接读成"命中率倍数"。 |
| **问题** | `132 / E[回收]` 是**回收倍数**；命中率倍数要解 `q*=(cost−L)/(H−L)`，两者数值不同。 |
| **修正后说法** | 明确区分并分别报告。修正后的盈亏平衡（**完整**奖金口径，`q*=(132−L)/(H−L)`，假设高低命中组内条件分布不变）：<br>• 九奖级平均浮动档：**q\* = 2.757%，倍数 1.99×**<br>• 七奖级基础档：**q\* = 3.070%，倍数 2.21×**<br>• 七奖级上浮档：**q\* = 2.601%，倍数 1.88×**<br>这些是**特定分布变化假设下的情景值**，不是任意策略的通用门槛。 |
| **证据** | `corrections/math_baseline_scenarios_v2.json`；测试 `test_breakeven_reports_payout_ratio_not_probability_multiple`、`test_breakeven_shapes_are_wellformed_and_not_generic`。 |

## C. 事实与口径类

### C1. 「二等奖被高估约 12 倍」——**事实错误**

| 项 | 内容 |
|---|---|
| **原说法** | 「二等奖实测均值约 18.6 万元，旧表高估约 12 倍」（出现在 4 个文件中）。 |
| **问题** | 数值错误。200,000 / 186,396 = **1.07**。 |
| **修正后说法** | 旧表固定 200,000 元相对**期数加权**实测均值为：九奖级期 **1.073×**、七奖级期 **1.371×**。真正的问题不是"水平高估"，而是**用一个常数替代了高度波动的浮动奖**（九奖级期实际区间 20,000 – 1,340,977 元，跨度约 67 倍）。 |
| **证据** | 官方快照 `official_dlt_draws.csv`；见本文件 §D 的复算命令。 |

### C2. 「盈利期比例」被当作「N 期累计盈利概率」

- **原说法**：把"74 期中 13.5% 的期数盈利"与"累计为正的概率"混在同一个结论里。
- **修正后说法**：**两者必须分开报告**。已实现指标是「盈利期比例 = 13.5%」；「74 期累计为正的概率」是另一个量（由分布决定，含偶发大奖），本轮**未计算**，需在 T4 用联合收益分布给出。

### C3. 「随机试验次数」被统称 1000 次

- **修正后说法**：按实际产物分别报告：
  - 样本外/回顾的 **C1（全号池随机）**：`n_trials = 1000`
  - 样本外 **C2（同候选池随机）**：`n_trials = 200`
  - 信号门槛的 **C3（随机择时）** 与 **C1**：`n_trials = 300`
  - 数学基线的蒙特卡洛：`mc_trials = 100,000`（结构校验另用 20,000）
- **证据**：`oos_only.json` / `full_run.json` 的 `n_trials` 字段与各 control 的 `n`；`gate_frozen.json` 对应脚本参数。

### C4. 「覆盖不了其余 71 期共 9,372 元的成本」

- **原说法**：把未中 3 个的期次当作全额亏损。
- **问题**：前区中 0/1/2 个**也有回收**（R(0)=5、R(1)=5、R(2)=115，七奖级基础档），低命中组的条件均值 **L = 18.95 元/期**。
- **修正后说法**：低命中组每期仍有约 **18.95 元**的期望回收，不能按 132 元全额计亏。

### C5. 「历史实际浮动奖均值 = 理论收益上限」

- **原说法**：「理论上限：5+12 的期望 ROI 在 −37%~−47%」。
- **修正后说法**：历史实测浮动奖均值构成的是**历史情景估计**，**不是**理论上下限。它依赖"未来浮动奖分布与所选历史窗口相同"这一假设，而该假设未被验证（奖池、销售额、中奖注数都会变化）。正确标注：**「基于历史逐期奖金的情景估计」**。

### C6. 「总体奖金计提比例（51%）单独证明所有条件策略不可能盈利」

- **修正后说法**：**降级**。51% 是**按销售额计提的总体平均**，它不排除"只在特定条件下投注"改变期望的可能性（虽然本轮没有找到这样的条件）。可作为**强烈的先验**，不能作为**排除性证明**。

### C7. 「所有历史实验不可能接触新数据」

- **原说法**：仅凭 `data/dlt/data.csv` 截止 26042 断言。
- **修正后说法**：限定为可核查的范围——「**本仓库 `outputs/` 下全部既有产物中，所有 `issue`/`期数` 字段的最大值为 26042**（逐文件解析确认）；生产数据文件 `data/dlt/data.csv` 的 mtime 为 2026-04-22、末期为 26042；RF 元信息的 `test_issue_end = 26042`。」这证明**本仓库的既有实验**未使用 26043 及之后期次；**不能**排除人工在公开渠道看过开奖结果。

### C8. 「没有数据泄漏」的适用范围

- **修正后说法**：应限定为「本轮实际检查的路径」：特征构建只用 `hist = data_asc.iloc[:idx]`；RF 静态模型按 `rf_train_end < issue` 隔离；信号门槛阈值只用滚动窗口内的过去分数；8 亿档位用开奖前奖池。**未**审计全部历史脚本、未审计人工操作流程。
