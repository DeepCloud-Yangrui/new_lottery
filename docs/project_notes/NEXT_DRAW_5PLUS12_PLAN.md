# 下一期 5+12 预测器：服务器实施计划（2026-11-03）

目标：按需运行一次，以当时已公开的往期开奖训练模型，在目标期开奖前输出唯一一组前区五号码，后区固定01–12。交付的是可追溯的研究预测，无自动下单、追加或倍投。本文件只做设计，不代表已训练。

1. **冻结策略与比较方式。** 复用 F1 配置和代码。固定小型 MLP（N）为展示用主模型，原因是它在原历史比较中是最接近均匀基线的学习模型，仍未优于均匀；不宣称能提高中奖率。以平滑频次 F、随机森林 R、均匀 U 作影子对照，各用同样的历史、目标期与 Top-5 平局规则。不给用户四组投注，不融合、不按近期命中或ROI切换主模型，不重复做历史选优。现有窗口10/30/100、初始化种子及训练超参数原样冻结。
2. **准备可核实的当期输入。** 在服务器研究分支核对 F1 实现和独立环境；由官方历史开奖接口生成带抓取时间和哈希的新快照，不覆盖旧研究数据。核验已开奖期号序列、跨年、重复期、号码范围及每期前后区唯一性；与冻结快照重叠部分逐期对照，冲突或漏期先对账。目标期、北京时间停售时刻取官方当期销售公告或销售状态，不用上一期期号加一。开奖历史更新与销售状态分别留存；缺任一证据或已经停售，停止出票号预测并给出具体原因。
3. **训练与选号。** 服务器 CPU 训练 RF；单张空闲 GPU 按已有三种子方案训练 MLP，F/U 不需拟合学习权重。训练标签截止到目标期之前最后一个已开奖期次。复用 build_front_training_dataset 和 build_feature_for_next_issue，不复用历史折的权重作为当前模型；标准化、内部早停只用训练历史。主模型生成35个边际概率，按原协议约束总和为5，以固定规则取前五并按号码升序展示。它优化预期命中个数，不把五个边际概率相乘当作全中概率。
4. **按需运行和留档。** 拟新增入口 python -m tools.predict_next_5plus12。默认自动核对官方在售期，也允许显式传入目标期但必须与在售证据一致。每次先检查是否已有该期预测；已有则返回原记录。训练结束再次检查停售时间，再以独占方式保存目标期、北京时间、前区、固定后区、主模型及对照预测、训练截止、数据/代码/配置/模型哈希与官方状态凭据。旧记录不可改写；主模型训练失败不冒充主模型输出。终端只显示一组主预测、生成时间、证据状态及66注/132元口径。实现和定向验收预算两天，本轮不设定时任务。
5. **验收。** 合成数据覆盖跨年、已停售、过期缓存、源间冲突、学习器训练失败、重复调用和同时调用。验证未来开奖变动不影响已有预测；35个概率有效且和为5；输出5个不重复前区号码，后区覆盖全部66对；同一预测记录可从模型与快照复算。先跑新测试和既有 tests/，再在真实在售期试运行一次。若没有可核实的期次，只交付通过验证的入口，不用演示号充当实预测。
6. **开奖后评价。** 在独立结果文件保存官方实际号码、各策略命中个数、按期Brier和相对U的差值。不回填预测记录，不把影子结果合成最佳号码。此前F1数据已暴露；后续仅将开奖前已有可信时间凭据的记录计作前瞻样本。本轮成功条件是能按时给出并复算一组预测，独立预测优势和长期净盈利仍须另行验证。
