## 2. 假设族（3 族 × 2 变体，预登记）

只使用**仓库现有实现**，不调参、不新增模型。

| 族 | 变体 A | 变体 B |
|---|---|---|
| **F1 选号信号** | `stat_miss_penalty`（S1 出厂默认） | `stat_miss_bonus`（P1 曾选出的变体） |
| **F2 候选池结构** | 单组 Top-10 + 规则过滤（S1） | 9 候选池 × 3 组贪心缩水（`n9_mix_441`） |
| **F3 组数（同预算）** | 1 组 / 期 | 3 组 / 期 |

**同预算规则**：比较不同组数时，以**总票款相等**为准。
3 组方案的成本是 1 组的 3 倍，因此把 3 组方案的期数截断到 1/3 再比较
（或等价地把 1 组方案的期数延长 3 倍，若数据允许）。

## 4. 计账（三本账）

每个政策用一个独立的 `SimAccount`；同一账户同一期的全部组**合并计税**，
税后净收益进入账本（`tools/profit_accounting.py`）。
来源标签逐期标注；估算回退不得标为官方实测。

---

## 5. 指标（预登记）

| 指标 | 定义 |
|---|---|
| `gross` / `tax` / `net` / `cost` / `profit` / `roi` | 账本口径 |
| `tax_share_of_gross` | 税额占税前回收比例（大奖被扣 20% 的体现） |
| `tail_contribution_top1/top3` | 最大 1 / 3 期利润占**正收益合计**的比例（尾部依赖度） |
| `prob_profit_positive_period` | **单期**净收益为正的比例 |
| `prob_cumulative_positive` | 用**期级 bootstrap** 估计的"N 期累计为正"概率 |
| `prob_touch_loss_limit` | bootstrap 路径中曾跌破 −500 元的比例 |
| `max_drawdown` | 从 0 起算 |
| `power` | 该窗口在 α=0.05（单侧）、power=0.80 下可检出的最小效应 |

**bootstrap 说明**：期级重抽样只反映**模拟不确定性**（用同一批已实现开奖重排），
**不增加开奖样本**。因此 `prob_cumulative_positive` 是"在这段历史分布下"的概率，
不是未来概率。

---

## 6. 统计设计（预登记）

- 家族错误率 **α = 0.05**（单侧，检验"优于对照"）；
- 功效 **0.80**；
- **效应量从税后盈利缺口推导**：D3 的缺口中位数约 66 元/期
  （q0.50 情景 −66.24 元/期）；
- 所需期数 `n ≈ (z_{0.95} + z_{0.80})² · σ² / Δ²`，其中 σ 为**单期净收益标准差**，
  由本轮数据实测后填入（**不得**预先假定）。
- 因 σ 含重尾（一/二等奖），**不使用正态近似替代**：样本量仅为参考，
  真正的判据是"观测差值 + 其重尾不确定性"。

---

## 7. 停止标准

- 若所有政策的**税后**净收益均显著为负，且与对照无可复现差异 → **停止该分支**；
- 若出现正收益，必须检查是否由**少数期次的大奖**支配
  （`tail_contribution_top3` 高），若是则标记为**未证实**，不得作为可靠下界；
- 无论结果正负，**负结果同样保存**。
