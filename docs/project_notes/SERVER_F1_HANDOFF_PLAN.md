## 3. F1修订：五候选、同特征、同时间块

沿用原F1的 U（均匀）、F（100期平滑频次）、L（L2逻辑回归）、R（固定RF），新增一个 N（小型MLP）；不加入GBDT、LSTM、Transformer或其他模型。U/F为基线，L/R/N为三个主要受评候选，不融合这些模型。

### N 的冻结设置

- 输入与L/R相同的历史表格特征；标准化仅fit当折训练部分；输出35个logits，以sigmoid得到边际概率。不得用35类softmax或把排序后的五个位置当五个独立分类任务。
- 网络：输入维度→64→32→35；两个隐藏层ReLU，各接Dropout(0.1)，输出层无激活。PyTorch float32，无BatchNorm、无混合精度、无学习率搜索。
- 优化：AdamW，lr=0.001，weight_decay=0.01，batch_size=64，最多200 epochs，BCEWithLogitsLoss均匀平均，不加正类权重。每epoch训练样本可固定种子打乱，训练/验证/测试的时间边界不得打乱。
- 训练折最后20%（向上取整）作为内部连续验证段；标准化只在前80% fit。每epoch按验证段最终概率的平均Brier选checkpoint，最小改善1e-6，patience=20，首次有效epoch为初始最好点，平局取更早epoch。
- 对每个种子在内部验证选定epoch后，重新初始化并在当折全部训练期fit标准化、训练恰好该epoch数；外部200期块绝不参与早停或权重选择。最终模型在外部块期间冻结。
- 固定种子17/42/2026，三次训练均执行、报告各自结果，N的预登记预测为三个原始概率向量的等权均值，再作sum(p)=5的统一logit偏移。N是一个固定种子平均候选；不可挑最佳种子，不能把种子当独立开奖样本。任一种子失败，该折N标记未完成。
- 固定Python/NumPy/PyTorch随机状态与数据加载器；启用可用的确定性设置并记录，确定性算子错误须修复/说明，不静默切换。复现承诺限于记录的环境，不承诺跨硬件逐位相同。

### 公平比较与判定

- 最近800个可建模期分4个非重叠200期块、扩展训练窗、首块训练≥500期；沿用既有10/30/100特征与min_history=120。全部是已暴露数据的历史时间顺序评估，不冒充新的未见测试。
- L/R/N都保留原始概率及统一sum(p)=5后的主评价概率；N先种子平均再修正，Top-5与原计划一样固定平局规则。三类模型使用同样外部期次和信息边界，MLP内部早停属于其预登记算法；比较时同时报告参数量/训练次数/耗时，不宣称三者计算量完全相等。
- 主指标仍为按期Brier。主要对比扩为 L-U、R-U、N-U；同一期配对差，块bootstrap长度20与50、2000次。Bonferroni家族alpha=0.05，每个双侧区间改为 **98.333333%**（尾概率0.05/6），替换旧两对比97.5%。区间只作依赖假设下的历史诊断。
- 候选晋级条件：总体较U改善、至少3/4块方向为正、两种块长度调整区间下界均>0；补充明确要求总体边际logloss不高于U且Brier不高于F。固定10个等宽概率箱报告校准，不以看图主观放宽晋级。全部候选未完成不得作完整胜负裁决。
- 多候选通过时选总体Brier最低者；绝对差≤1e-12视为平局，优先L、R、N。Top-5平均命中、K分布、中3+/4/5和完整税后收益仅作分层诊断，不能反向选模型。统计改善≠联合命中改善≠盈利证明。
- 不通过则关闭该轮，通过也只交付待后续未见数据验证的冻结候选，不自动延伸模型搜索、前瞻或投注。
