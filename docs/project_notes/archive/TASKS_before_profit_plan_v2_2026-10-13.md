## 2. 阻塞与待确认

### 已解决的阻塞（保留记录）

**阻塞 1（已解决）：回顾窗口重算耗时。**
RF 逐期推理约 1.15 秒/期。通过给 `StrategyRunner` 加
`(数据集标签, 期索引)` 级缓存（RF 排名与 profile、计奖口径无关），
把 RF 调用从 6,800 次降到 1,774 次，全量运行约 40 分钟完成。
先前的样本外冒烟进程曾被系统因**内存紧张**终止，之后改为串行、分批执行。

**阻塞 2（已解决）：信号门槛样本外无法评估。**
在 74 期样本外窗口上 warmup 后的可用下注期太少，统计意义有限。
改为在**最近 500 期**上评估 S3，并配 `run_random_same_bet_count_baseline`
（随机参与期次、相同下注次数与组数）作为择时对照。

1. **样本外窗口只有 74 期**，对"是否盈利"统计功效极低：

2. **对抗性核查未完整执行**（71 个子代理因 API 额度耗尽失败）。
   关键条款由本人一手抓取复核，属"单人核验"而非"多方独立核验"。
3. **07001–19018 的规则原文未取得**，该期段结论仅为逐期数据反推（低置信）。
   本轮所有评估窗口均不涉及该期段。
4. **派奖的资金计提来源、以及"派奖注数少于中奖注数"的条款级解释未取得**；
   本项目采用"全额派奖"（因单票 132 元满足门槛）并同时报告保守下界。
5. **固定奖存在"限额赔付"的极端下界条款**，历史未触发。
6. 结论只对 **≤ 26116 期**有实证支撑；规则若再变更必须重新核验。
