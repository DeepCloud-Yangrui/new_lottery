### 3.1 L 的失败模式诊断

L 的退化幅度远超其他候选，值得单独说明，因为它**不是实现错误**：

- 在**训练折内**，L 的原始概率之和恰为 **5.000**；在**评估期**上却是 **7.14 / 7.39 / 8.37 / 8.61**。
- 原始概率与真实标签的相关性约 **−0.01 ~ +0.02**（基本为零）。
- 训练集 Brier 低、评估集 Brier 高 → 典型过拟合。

**成因（经对抗性复核的受控实验更正）**：

训练折内 sum=5.000 并**不是**特征共线造成的，而是 sklearn 逻辑回归**截距不受惩罚**的
直接结果：截距的得分方程逐输出满足 `Σᵢ(yᵢⱼ − pᵢⱼ) = 0`，
而每期标签恰好 5 个 1，故样本内每期概率之和必然为 5（去掉截距后同一设计矩阵为 17.48）。

真正的驱动因素是**线性预测子的离散度在样本外放大**：
样本内 logit 均值/标准差为 **−2.3585 / 1.4206**，样本外为 **−2.3241 / 2.9380**
（均值几乎不变，标准差翻倍）。由于 sigmoid 是凸函数，
`E[σ(η)] > σ(E[η])`，于是平均边际概率被抬高，每期原始概率之和升到约 8.6
（正态近似 `35·E[σ]` 给出 8.68，实测 8.61）。把样本外 logit 的均值/标准差
拉回样本内水平即可让和回到 5.11，并把原始 Brier 改善到 0.1443——直接印证该机制。

受控对照：删掉设计矩阵中 8 个**精确线性相关**的列（秩亏确实存在，秩 245/253）
后，样本外原始 sum 为 8.5886（全列为 8.6098）、原始 Brier 为 0.2199（全列为 0.2248），
**基本不变**——即"去共线化"并不能缓解该现象。
该效应是 L 特有的：同样特征下 R 的和为 5.03–5.43、N 为 5.44–5.90。

补充：sum(p)=5 的固定修正对 L 是**帮助**而非损害
（原始 Brier 0.181–0.225 → 修正后 0.159–0.176）。即失败源于 L 本身，
不是修正口径造成的。
